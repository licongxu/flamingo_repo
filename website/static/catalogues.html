Query a halo catalogue

Filter clusters by mass, redshift, and detection significance (q_from_mz, where available), preview rows here, or export the selection as CSV. The same queries are available programmatically, e.g. GET /api/v1/catalogues/{id}/query?min_M500c=1e14&max_z=0.5.
